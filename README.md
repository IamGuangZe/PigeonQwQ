## 关于本项目
本项目是我个人为了学习高版本 Minecraft 客户端开发而创建的项目，仅供娱乐和教育目的使用。
我只有一些其他编程语言的基础经验，并不精通 Java 或相关技术。这个项目是临时起意制作的。
* （本项目不制作绕过反作弊的功能。本项目仅供娱乐和学习一些 Java 知识。如果你使用本项目的内容，我对任何账号封禁不承担责任。）

## 功能特性

本项目的部分功能设计用于 Hypixel 小游戏和 Skyblock。
大多数功能都很简单，仅供个人实验使用。
