## About This Project
This project is created by me as a personal learning experience for developing high-version Minecraft clients. It is intended for entertainment and educational purposes only.
I only have some basic experience in other programming languages and am not proficient in Java or related technologies. This project was made on a whim.
* (This project does not make features that bypass anti-cheat. This project is only for entertainment and to learn some Java. If you use content from this project, I am not responsible for any account bans.)

## Functionality
Some features of this project are designed for use in Hypixel minigames and Skyblock.
Most features are simple and intended for personal experimentation.
